# TEC International — демо нового сайта

Демо по презентации «Обновление сайта tec-inter.kz» (материал для обсуждения и основа ТЗ).
Живая версия: http://tec-inter26.alexte1.beget.tech/ — закрыта от индексации (noindex), чтобы не дублировать tec-inter.kz.

## Страницы

| Адрес | Что на странице |
|---|---|
| `/` | Главная: первый экран, «Почему нам доверяют», 10 направлений, 11 отраслей, комплексный подход, проекты, партнёры, заказчики, форма |
| `/solutions/` | 10 направлений с якорями (`#networks`, `#security`…) и «Подобрать решение» по отрасли (`?industry=energy`) |
| `/projects/` | Проекты «задача → решение» с фильтром по отрасли |
| `/partners/` | Партнёры по направлениям, статус под логотипом, ссылка на решения |
| `/about/` | Вкладки: О нас, История, Команда, Сертификаты и благодарности, Нам доверяют (`#certificates` и т.д.) |
| `/news/`, `/news/<slug>/` | Список с фильтрами и страница статьи с блоком заявки |
| `/contacts/` | Контакты (адрес — только здесь) и форма |
| `/sitemap.xml` | Карта сайта генерируется автоматически |

Кнопка **«Показать пометки ТЗ»** в верхней полосе включает номера с пояснениями из презентации — удобно показывать заказчику.

## Устройство

- `index.php` — единая точка входа (ЧПУ через `.htaccess`), 301 со старого `/proekty/`.
- `inc/data.php` — весь контент: направления, отрасли, партнёры, проекты, документы, статьи. Заглушки помечены `___`.
- `inc/helpers.php` — шаблон страницы (шапка, подвал, модалка заявки), иконки, формы.
- `pages/*.php` — страницы.
- `api/lead.php` — приём заявок: пишет в `storage/leads.log`; почта и Telegram включаются в `inc/config.php`.
- Код совместим с PHP 5.6 (сейчас на хостинге) и 8.x.

## Выкладка

```bash
bash deploy.sh
```

Архив уходит по SSH (ключ `~/.ssh/beget_hosting`) в `~/tec-inter26.alexte1.beget.tech/public_html`, на сервере все PHP-файлы проверяются `php -l`.

## Перед запуском боевого сайта

- `inc/config.php`: `demo => false`, `site_url`, адреса для заявок (почта + Telegram).
- `robots.txt`: открыть индексацию и указать sitemap.
- Подставить реальные статусы партнёров, годы истории, число инженеров, фото, сканы документов.
